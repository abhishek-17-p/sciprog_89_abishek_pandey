1. Code magic.c is a c compiler that reads a txt file, allocates the 
matrix to pointer arrays, and prints whether the matrix is a Magic square
or not. 

2. Code magic.c consists of #include "magic.h", which calls the function. 

3. Code magic.h is a Magic square function that return 0 if any of the check
fails and prints 1, if it is a magic square. 

4. Square.txt consists of 3*3 matrix. 

5. To compile, gcc magic.c -o out -Wall. It will then ask for filename containing matrix of any order.
