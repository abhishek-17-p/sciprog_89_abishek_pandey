1. Code prac6.c is c compiler code for matrix multiplication C = A * B, where
A = 5*3, B = 3*4 and output we get as C = 5*4.

2. Code prac_6.c is c compiler  code for the same matrix multiplication, 
but using matmult function to do the multiplication. 

3. mm.c comprises with matmult function.

4. Makefile compiles prac_6.c and mm.c and links them into one executable.
